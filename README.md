# TQC 專案管理概論｜GitHub Pages 互動測驗

這是一個完全自包含的 GitHub Pages 網頁版，只有一個 `index.html`，題目、CSS、JavaScript 都已內嵌。

## 題庫
- 第一類：60 題
- 第二類：20 題
- 第三類：130 題
- 第四類：130 題
- 第五類：60 題
- 第六類：20 題
- 合計：420 題

題目與答案依提供的《TQC 專案管理概論》題庫文字檔製作。
題庫本身只有 `Ans:` 答案欄，沒有獨立文字解析，因此「解析」區會明確標示此限制，不自行捏造題庫解析。

## 發布到 GitHub Pages
1. 在 GitHub 建立一個新的 Repository，例如 `tqc-project-management-quiz`。
2. 將本資料夾中的 `index.html` 與 `.nojekyll` 上傳到 Repository 根目錄。
3. GitHub：Repository → Settings → Pages。
4. 在 Build and deployment 選擇 `Deploy from a branch`。
5. Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
6. 等待 GitHub Pages 部署完成後，會產生：
   `https://你的GitHub帳號.github.io/tqc-project-management-quiz/`
7. 之後把這個網址放到 iPad Safari，點開即可直接作答。

本版本不需要 Node.js、資料庫、外部 JavaScript CDN 或其他伺服器。
